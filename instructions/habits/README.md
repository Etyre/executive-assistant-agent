# Habit documents

Put one Markdown file per habit or system here (or ask the agent to write one from a conversation). The
agent reads them with `list_documents` / `read_document` and uses them as the yardstick when it watches
the metrics. A useful shape:

- **What**: the behaviour, in one line.
- **Why**: what it protects or produces.
- **Rule / TAP**: trigger → action, with the exact numbers (bedtime, minutes, days per week).
- **Metric**: which data source shows whether it happened (Toggl project, Focus Monitor metric, Oura
  field, Sleep Bandit cell, exercise log, checklist row) and what counts as off track.
- **Status**: new / settling / robust, and since when.
- **Known blockers** and what has worked against them.
